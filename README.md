# Buildify

Buildify is a Windows desktop tray app for monitoring GitHub Actions. It connects to your GitHub account, lets you choose which repositories to follow, polls workflow runs in the background, and sends native notifications when builds finish.

The portfolio download link points to the GitHub Releases version of the app.

## Current Features

- Windows tray app built with Tauri, React, TypeScript, and Rust
- Native Windows notifications for completed GitHub Actions runs
- Dashboard with connection status, polling status, repository count, running workflows, latest completed runs, and recent activity
- Repository follow list with `All`, `None`, and refresh controls
- Settings view for GitHub token management and polling interval selection
- Connection testing and automatic reconnect attempts
- Light and dark theme toggle
- Tray menu actions for open, check now, pause/resume, and quit
- Single-instance behavior so opening the app again focuses the existing window
- Close-to-tray behavior instead of fully exiting the app
- Local persistence for settings and seen workflow runs to avoid duplicate notifications

## How It Works

Buildify uses a GitHub personal access token to fetch your repositories, filter for repositories with GitHub Actions enabled, and check recent workflow runs at the selected interval.

Notification behavior:

- Existing runs are marked as seen so first-time setup does not spam notifications
- Running workflows are tracked while queued or in progress
- Notifications are sent when a tracked run completes
- Completed runs opened from the app link directly to GitHub

## GitHub Token Setup

Create a fine-grained personal access token from:

- [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)

Recommended permissions:

- `Metadata: Read`
- `Actions: Read`
- Repository access: `All repositories`

Paste the token into Buildify and use `Test connection` or `Save settings`.

## Development Setup

### Requirements

- Node.js LTS
- npm
- Rust
- Cargo

### Install dependencies

```bash
npm install
```

### Run in development

```bash
npm run dev
```

The Tauri app opens in a desktop window. Closing the window hides it to the tray.

## Build the Windows App

```bash
npm run build
```

Build artifacts are generated by Tauri under `src-tauri/target/release/bundle/`.
